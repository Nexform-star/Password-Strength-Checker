# Password Strength Checker

A beginner-friendly Python script that evaluates password strength based on several criteria.

## Features

- Checks password length
- Detects digits
- Detects uppercase and lowercase letters
- Checks for special characters
- Calculates a score out of 5
- Classifies passwords from Very Weak to Very Strong

## Requirements
 
- Python 3.14 or a compatible Python 3 version

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Nexform-star/Password-Strength-Checker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Password-Strength-Checker
   ```
3. Run the script:
   ```bash
   python main.py
   ```
